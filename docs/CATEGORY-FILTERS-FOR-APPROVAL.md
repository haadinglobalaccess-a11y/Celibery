Notes
- "باور بانك" and "رؤوس الشحن" follow common Saudi retail usage; alternatives are "شواحن متنقلة" and "شواحن جدارية". Please confirm.
- Filters only appear when products in the category actually have those values (no empty filters).
- "All products" and search results show only Price and Availability, because other filters do not apply across categories.
- Cable length is not a filter yet; it can be added if CELIBERY wants it.
